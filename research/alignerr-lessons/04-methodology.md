# Reader 4 — Experimental methodology (moat_search + memory laws)
Screening ladder (cheapest first): −1 paper rejection + novelty scan; 0 can the best-case even do it (oracle 13% → dead in 5 min); 0b instrument sanity (scored coord responds; swept knob reaches physics — non-bit-identical rows); 1 duel-screen reflexive vs lowdim CEM vs highdim over ONE cost, alive only ≥1.5× both; 2 ablate each info source; 3 real agent probe. "No candidate gets a design note before it has a row in the results table."
Baseline honesty: under-tuned baseline = false positive, under-powered oracle = false negative. Fixes: don't cap the cost (starves gradient); RESIDUAL arm (plan = baseline + corrections so search strictly contains baseline); never handicap the oracle as the IV grows. Gain-sweep the reactive arm always. Equal budget; evaluate the hand-picked point as candidate 0. Reference = best-known technique, not what you wrote (agent 1.000 vs author's 3.1/9). Never anchor at what you hand-tuned; breached ceiling → better anchors. Build a conservative AND an aggressive arm before "no fair reference". Absolute tolerance gates every ratio.
Bug → tell: wall-clock budget under Pool(6) → rows pinned 3dp while others drift; private generator re-impl → bit-identical after change; hardcoded path → reference exactly 0.000; module singleton → 0.98→0.18; solve.sh ignores variant → ref ≈ oracle; sweep redrew RNG → control row fails to reproduce; stale remote param → arm pinned at cap; failed exec → "running" with no result; sim divergence → uniform cost; cross-machine → one machine; hollow agent pass → 0.000 with turn_limit. META: every wrong table caught by a cross-check → sanity cell first.
Decision rules: 1.5× screen; ~2× ship (oracle_raw > agent_raw/0.8 + 0.15); day-one: agent within 20% of oracle → dead; screens 3 seeds×3 draws median; anchors 12–40 episodes; ship gate 5-run avg; both ablation directions agree; kill criteria PRE-REGISTERED at matched finish time; record table + ratio + verdict + "THE LAW THIS BUYS".
Kill-log shape: verdict+date → thesis → table → structural reason → ★ law → honest caveats → reusable → redirect; own claims killed as prominently as candidates.
Time lessons: build-before-screen; refining features off the crux (run the killable rung first); decorating a settled conclusion; designing by imagination in a saturated space; chasing cosmetic targets ("do not destroy a working configuration"); explicit RAM/core budgets; append-only logs.
Fable when attacking: solves classic control 1.000; bypasses disclosed derivations (finite-differences the sim); sys-IDs anything observable; big stacks fine; uses public replay + wall clock; optimises exactly the disclosed objective. Can't: acquire nonexistent data; hedges under true partial obs; fumbles blind/degraded sensing + contact; greedy (drops hardest row to ~0); runs out of turns → vacuous 0. Steering: real score not proxy; LAST score + trajectory; low-but-nonzero trustworthy; read failure reason; when beaten, re-implement the agent's own best as the baseline.
