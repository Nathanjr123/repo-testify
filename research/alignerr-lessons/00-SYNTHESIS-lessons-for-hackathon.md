# What the Alignerr project teaches, carried into the micro1 Frontier Engineering Challenge
Sources: four deep reads of /home/nate/lbx-rl-tasks-template (harness+acceptance stack; two shipped tasks; guidelines+CI; _moat_search methodology + memory laws). Detailed reports 01–04 beside this file.
Rubric tie-break order: Agent Solution & Engineering > Reproducibility > Measured Improvement > End-to-End Quality. Gate first: eligibility, completeness, integrity, traces, reproducibility.

## A. What transfers DIRECTLY (the edge)
A1. Anchored measurement → "Measured Improvement". Repo: naive→0.0, reference→0.5, oracle→1.0; anchors FROZEN before the agent is evaluated; MAX not average; calibration = piecewise map in the scorer; "baseline = the STRONGEST obvious weak strategy". Hackathon: baseline = strongest obvious weak strategy at the SAME budget as advanced, tuned; advanced = best-known; report raw AND anchored deltas per row, mean + lower-tail + worst; freeze scorer+cases BEFORE building advanced.
A2. Scorer patterns. Rows capped (≤0.20 each; 3–6 rows fine here), bands (full-credit edge, zero-credit edge) per case then aggregate. Gates MULTIPLY, rows ADD, nothing is both. Conjunctive cap when objective incomplete on <50% of cases. Lower-tail 0.55·mean + 0.30·bottom-30% + 0.15·worst. Non-finite→0; no-op check; invalid submission→0+reason code; grader fault→internal error never a penalty. Raw quantised 3dp; fixed seeds. ONE aggregate fn shared by grader and every measurement script. Replay CALLS the grader path, never copies it. Measure each row's distribution BEFORE banding (dead / saturated / crushed rows; re-banding moved a gap 0.059→0.169). Fallback must not out-score a real attempt. Missing measurements clamp to the row's zero edge.
A3. Evidence chain. build_proof fields: schema_version, tree hash (binds results to source), image digest, base image, platform, built_at, duration, tool version, result{graded_at, score, per-case[], breakdown, weights, run_dir, artifact paths}, review_artifacts[{path, sha256, bytes, w, h}]. STALENESS: results dropped if tree hash changed → full proof re-run is the FINAL step. calibration_evidence keys: anchors, freeze_note, band_widths (asymmetry DISCLOSED), policies[]{command, source, raw, calibrated, provenance}, oracle_selection{train/heldout/grading + REJECTED overfit}, what_the_agent_fails_at. README cells ↔ JSON fields 1:1; GENERATE tables from proof (live branch has 0.741/0.679/0.662 for one oracle).
A4. Ablation / self-attack → "one experiment you removed" + "main failure mode". Belt kill in 28 README lines: independent controller → real grader → ablate each info source → whole mechanism worth 0.035. "never asked WHICH input produced it." / "A parameter search over the wrong functional form is not the agent ceiling." Drone: per-component ablations RE-TUNED at full budget; overfit rejected via held-out (0.72 train / 0.30 held-out). → ablations/ dir, one flag per component, table in README; the flat one is the removed experiment; the one whose removal hurts most is the video's "biggest change".
A5. Measurement-bug tells → sanity cell first. Bit-identical after a change = didn't land. Rows pinned at 3dp while others drift = truncation. Exactly 0.000 = path bug. Control row fails to reproduce = whole sweep junk. 0.000 with turn_limit/no artifact = hollow run. One machine for decisive numbers. "Every wrong table was caught by a cross-check, never by the number looking wrong."
A6. Doc style. instruction = engineering assignment: exact paths, API shapes/units/bounds, every gate/cap/aggregation disclosed, ban vague words, prompt and grader must AGREE. DESIGN = measured-table-first + self-criticism. Kill-entry shape: verdict+date → thesis → table → structural reason → ★ the law this buys → honest caveats → reusable → redirect. Changelog entries use this; the hot take is a "law this buys" with a table under it.
A7. Provenance headers. "PROVENANCE — read before modifying": what is ours / what is NOT ours and was previously claimed here. Every agent-written file gets one (agent, session, what you changed).
A8. Trajectories. {index, type, name, content, tool_calls, usage}; "Step NN — thinking / tool call / tool result"; persisted on pass AND fail; finish_reason; every attempt recorded. Export Claude Code jsonl to that shape + rendered md; keep failures; mark human checkpoints; summary table (session, model, purpose, steps, tokens, outcome, what changed after).
A9. Video. Must SHOW the objective completed; verify by WATCHING frames (two passes probed as valid mp4 and showed nothing; a silent writer produced an 8-byte mp4 — assert size); pick the demo case where every mechanism fires. Script: problem → baseline → advanced on SAME case → comparison → changelog → biggest change → removed experiment.
A10. Fable's habits. Optimises exactly what it can measure → give it the scorer early. Collapses the hardest case while maximising the mean → lower-tail row. Runs out of turns and writes nothing → read finish_reason. Keep LAST score+trajectory not best; low-but-nonzero is the trustworthy signal; when it beats your baseline, adopt its architecture with provenance and re-measure.

## B. What NOT to carry over
Moat thinking (no adversary; you WANT advanced high). Hidden data (public/held-out SPLIT, not secrecy). 10+ rows / 40 seeds / Taiga band shapes / 1280x720. "<2× → kill" (an honest 1.3× with ablations beats a claimed 5× without). Months of screening → 2 hours Friday night. Decorating a settled conclusion; chasing a cosmetic target.

## C. Twelve working rules for the 57 hours
1 Scorer+cases+replay before any solution; freeze; commit hash. 2 Sanity cell first in every measurement. 3 Baseline = strongest obvious weak strategy, equal budget, tuned; anchor recorded before advanced exists. 4 Public/held-out; reject in writing what wins public and loses held-out. 5 Measure rows before banding. 6 Gates multiply, rows add, nothing both. 7 Ablate every component, re-tuned, table. 8 Bit-identical = didn't land; stop. 9 Every number → proof entry {cmd, seed, git hash, ts, runtime, cost}; tables generated. 10 Full proof re-run is the final act; no edits after; tree hash in README. 11 All traces kept incl. failures; checkpoints marked; provenance headers. 12 Pre-register Friday night: advanced idea's kill criterion + Sat 18:00 checkpoint; if unmet, ship best surviving variant and write the kill entry.
