# Reader 3 — Guidelines + reviewer bar
Bar: naive 0.0; max local Claude < 0.50 (exactly 0.50 fails); max Boreal < 0.50; reference 0.5 from MEASURED performance not a scorer branch; oracle 1.0 with documented privileges. MAX is the statistic; frozen before agent eval. Baseline = STRONGEST obvious weak strategy, valid, reproducible under baselines/ with README. Rubric 10+ criteria (min 5), four strata. Calibration realism reviewed: upper band ≥ ~0.15, near-symmetric halves, agent/oracle raw well under 80%; moderate_calibration_anchor_realism + reward_hacking are blocking checks. Determinism pinned; no LLM judge. Accepted = agent consistently < 0.50, SME-reviewed, genuine simulator use, resistant to trivial solutions.
Writing: instruction.md = engineering assignment — exact paths, API shapes/dtypes/UNITS/bounds, public files, objective, components, threshold, EVERY gate/cap/aggregation + public calibration shape ("hidden score cliffs must not be used"); ban vague words; prompt and grader must AGREE. DESIGN/VALIDATION: measured-table-first + self-criticism ("A reward-hacking hole this process found — in our own scorer"; "REVISION HISTORY — every fix forced by a measurement"); scorer header carries calibration rationale with all arms' raws.
Videos: rendering.mp4 1280x720 h264, harness-verified, hashed in proof; must SHOW the objective completed; revise on clipping/impossible motion/failure despite 1.0/partial behaviour rewarded.
Trajectories: CI fails without trajectory.json; harness_summary.json {status, score, runtime, model, grade, head_sha, paths, rubric_quality, run url}; ceiling 0.50; authors record model, config, attempt count, EVERY attempt score, max, run id; validation table per-submission score/raw/avg/worst + "Interpretation" paragraph; "Did the model avoid a perfect 1.0?"
Decision docs: CANDIDATES.md selection law revised by three kills; 4-criterion screen (planning required / plan space searchable cheaply / execution hardness survives known plan / novelty); criterion 2 screened FIRST; kills kept with skull+date; "no plant work until the arithmetic is written down". DECISION_BRIEF.md: PROVEN → corpus scan → REFRAME → 3 options w/ risks → RECOMMENDATION → "what I need from the user (the bottleneck, honestly)". Kill notes: "STRUCTURAL NO-GO… kept for the lesson".
Rejections: sparse reward; degenerate solutions; instability as reward hacking; single-condition rollouts; non-determinism creep; vacuous matches; per-item metrics over items reached (farmable); rubric pitfalls (prescriptive/ambiguous/misaligned/formatting/golden values) — "design a harder task rather than a more arbitrary rubric"; reimplementing shared infra; env traps (baked ENV var → all 0); one task per PR. Skip list: rubric.toml, calibration.json, variant detection, source markers, survival credit above threshold when incomplete.
CI: every commit — files, schemas, compute_score signature, return in [0,1], outputs, image builds, proof fresh + 1.0 + artifacts. run_qa — static → runtime → proof verify → ground-truth run → upload → Boreal export → agent harness + trajectory → ceiling → Auto QA → summary/comment → dispatch. PR template: description, verbatim instructions, assets, grading strategy, local-validation checkboxes.
